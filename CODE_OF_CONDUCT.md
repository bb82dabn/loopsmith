# Code of conduct

LoopSmith welcomes contributors and users of all backgrounds and experience levels.

- Be respectful, constructive, and patient.
- Critique ideas and code, not people.
- Respect privacy and do not publish another person's personal information.
- Do not engage in harassment, threats, discriminatory abuse, sexualized conduct, or sustained disruptive behavior.

This policy applies to project issues, pull requests, and other official project interactions. Maintainers may edit or remove harmful content, close disruptive threads, or restrict participation. Enforcement should be proportionate and consider context; maintainers are subject to the same expectations.

To report harmful content on GitHub, use the content's **Report content** option. For sensitive concerns, contact the repository owner through an available private channel listed on [their GitHub profile](https://github.com/bb82dabn); do not expose personal information in a public issue. This project does not promise a dedicated confidential reporting mailbox or response SLA.
