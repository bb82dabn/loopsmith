# LoopSmith

**Short description**

Forge deterministic, seamless game-music loops in your browser and export MP3, WAV, MIDI, or editable projects.

## Description

**Create original, seamless background music directly in your browser.**

LoopSmith builds deterministic, roughly one-minute game-music arrangements from a seed and musical controls. Choose a scene, shape the mood, then regenerate the whole composition or individual layers until it fits.

### Features

- Ten game-scene presets, from peaceful villages and forest exploration to battles, boss fights, and science-fiction menus
- Deterministic seeds and numbered variations for repeatable results
- Controls for style, mood, tempo, key, scale, intensity, instrumentation, and complexity
- Layer locking, duplication, regeneration, mute, solo, volume, pan, voice, and octave controls
- Piano-roll visualization and seamless loop playback
- Game-ready MP3, reference WAV, standard MIDI, and editable LoopSmith project exports
- Fully local processing with no account, uploads, analytics, database, or application server

### Quick start

1. Choose a scene preset and adjust the musical controls.
2. Enter a seed and select **Generate composition**.
3. Audition the loop, adjust the mixer, or regenerate individual layers.
4. Export MP3 for normal game use, WAV for exact loop diagnosis, MIDI for another sequencer, or an editable project for later.

### Generation and licensing

LoopSmith uses a procedural composition system with sequence-free aggregate musical statistics derived from 25 attributed CC-BY 4.0 MIDI works. No source melodies, chord sequences, rhythm templates, samples, or audio are included. Corpus attribution, software licenses, third-party notices, and corresponding source are supplied with the release.

Generated compositions are original procedural output, but creators should review every export before commercial release.

This project contains AI-assisted development output, as declared through itch.io's AI disclosure field.
